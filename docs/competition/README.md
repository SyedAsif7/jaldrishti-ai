## 🏛️ Grounding & Transparency Declarations

In strict adherence to the competition's evaluation standards:
1. **Status of Current Prototype**: Fully functional local and deployable web application (React + TypeScript + FastAPI) covering all 8 Marathwada districts (*Chhatrapati Sambhajinagar, Jalna, Beed, Dharashiv, Latur, Nanded, Parbhani, Hingoli*).
2. **Current Datasets**: Operating on 25-year historical observation series (IMD, GSDA, WRD) with clearly marked simulated demonstration parameters for software verification.
3. **No Fabricated Claims**:
   - Zero claims of formal government partnerships or certified deployments prior to pilot sanction.
   - Zero claims of live IoT hardware integration (telemetry connectors are designed and ready for pilot deployment).
   - Machine learning accuracy metrics reflect real holdout test evaluations (2019–2024 holdout) without inflated or fabricated claims.
